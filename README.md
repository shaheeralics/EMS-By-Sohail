## 🌟 Overview

**Pawanda** is an enterprise-grade E-Commerce Automation platform powered by AI. It seamlessly integrates a **Google Gemini-backed WhatsApp Agent** with a beautifully designed, high-performance Admin Dashboard. 

Designed to operate autonomously, the AI handles live customer conversations, product catalog inquiries, intelligent price negotiation (with strict boundary adherence), and end-to-end order processing—all visible in real-time through the premium Dark Mode dashboard.

---

## ✨ Core Features

- 🤖 **AI WhatsApp Agent:** Fully autonomous AI agent capable of conversational commerce, dynamic negotiations, and handling custom business policies.
- 💬 **Live Conversations:** Real-time monitoring and takeover capabilities for active AI-customer WhatsApp threads.
- 🛍️ **Advanced Product Catalog:** Manage products with rich media (Images, Videos, and AI Voice Notes), setting asking prices and absolute minimum negotiation thresholds.
- 📦 **Order & Invoice Management:** Professional document-style order processing with dynamic invoice generation (Original Price vs. Negotiated Discount).
- 📈 **Analytics & Insights:** Granular KPIs, sales trends, top-selling products, and revenue tracking.
- ⚙️ **AI Customization:** Define exact business rules, prompt injections, and predefined voice profiles for the agent.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MySQL Server (XAMPP or standalone)
- Google Gemini API Key

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sohail-ahmed-26/ecomerce-automation.git
   cd ecomerce-automation
   ```

2. **Setup the Backend:**
   ```bash
   cd backend
   npm install
   # Configure your .env file with DB credentials and API keys
   node setupDb.js # Run migrations
   npm start
   ```

3. **Setup the Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
